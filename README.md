# Northstar

A lightweight static sales-page starter.

## Structure

- `index.html` — homepage
- `assets/css/style.css` — responsive site styles
- `assets/js/main.js` — homepage behaviour
- `assets/images/` and `assets/fonts/` — shared visual assets
- `data/site.json` — central site details for future templating or scripts

Open `index.html` in a browser to preview the site. Additional standalone pages can be added at the project root or in their own folders as the site grows.
